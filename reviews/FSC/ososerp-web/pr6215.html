This PR fixes Legal Entity bugs (FSC-758, FSC-760). It reworks the form save orchestration, primary-location linking, logo preview, and async validators and error messages. It adds resolvers for locations and companies, and adds a company dropdown to the Location master form. The PR is open.

The save-update path can partially fail. If the primary-location link fails after the company update has succeeded, the user sees a generic save error and the section does not advance. The calendar update is fire-and-forget. The create path shows both an error and a success message. Fix these before merge.

The team must confirm that the backend exposes the new /code/{code}/id/{id} route, because failures are silently swallowed. They should also decide whether client-side filtering of all active locations is acceptable. The PR description is empty and no tests were added.

Method: 4 independent review calls over 1 shard(s), evidence machine-checked (0 unverifiable candidates discarded), then one merge call.
