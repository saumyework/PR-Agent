This PR converts the Fleet Contact backend. It adds a ContactService, CQRS commands, queries and handlers, endpoints, DTOs and mapping extensions, plus localization keys in three resx files.

Merge is blocked by multi-tenant isolation gaps. By-id operations, GetByCompany, the ignition lookup, and the code and ID-number uniqueness checks are not company-scoped. Update can move another tenant's contact into the caller's company. Update also skips the code and mobile uniqueness checks that Create performs. Create may use contact.Id before it is assigned, and null collections in the DTOs cause NullReferenceExceptions.

The team should decide how archived contacts are listed and whether ID-number uniqueness is global or per company. The PR has an empty description and no tests.

Method: 4 independent review calls over 1 shard(s), evidence machine-checked (1 unverifiable candidates discarded), then one merge call.
