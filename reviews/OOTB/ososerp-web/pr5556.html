This PR adds a new "Request Status" pill column to the SDM Requests list (distinct from the existing workflow "Status" column), reusing and extending the shared IconColouredPill pattern in DatatableV2Component. It also fixes the priority column to use the same pill style, adds a status-dot variant to the pill renderer, fixes a CSS bug where a var(--...) fallback color produced invalid CSS in the pill's tint calculation, and corrects a dictionary-store key that was silently breaking the new column's filter dropdown.

All files are Angular/TypeScript, reviewed against the Angular guide and cross-cutting naming conventions. No backend/validation surface is touched. Verified against sibling code in the repo (via gh api) that the Request model fields referenced (priorityColor, requestStatusName, requestStatusColor, requestStatus.lookupValue/.color) genuinely exist, and that the dictionary-store rename does not orphan any other caller.
